# 长征问答 · 五千里一关

一个以长征为背景的**多页面**闯关问答网站。纯前端、零依赖，打开浏览器即可游玩和阅读。

## 页面结构

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 首页 | `/` | 长征进度、环形里程、开始闯关、长征故事入口 |
| 闯关 | `/game.html?level=1` | 单关 5 题、50 血对战、结算与敬礼动画 |
| 长征故事 | `/story.html` | 中国地图上的 8 个长征故事地点 |
| 故事详情 | `/story.html?id=xiangjiang` | 直接定位到中国地图上的某个地点与故事 |
| 题库 | `/bank.html` | 30 道长征题，选择题 + 判断题对照 |
| 战绩 | `/records.html` | 每关最高答对数、通关状态、尝试次数 |

首页、题库、我的成就、长征故事采用夕阳浅红纪念版视觉；闯关保留深色对战界面，背景改为同色系日出场景。所有页面通过顶部导航互相链接，避免游戏界面与阅读内容混在一起。

首页采用「长征行军档案」式布局：夕阳浅红渐变纸底、红印章、左侧主标题与出发入口，右侧环形长征进度和五个里程节点；标题背后是一轮随通关进度逐渐升起的日出太阳，五关全部通关后完全升起。下方是长征故事阅读条、诗句与数据汇总。进度区保留 25,000 里总里程、5 个 5,000 里节点、已通关数量、最佳答对数和当前关卡。

## 玩法

- **五关长征路**：每 5,000 里一关，共 5 关（5,000 / 10,000 / 15,000 / 20,000 / 25,000 里）。
- **每关 5 题**：从本关 6 道长主题中随机抽取 5 道，并按长征历史事件顺序出题。
- **随机题型**：每题随机呈现为四选一选择题或判断题。
- **50 血对战**：
  - 我方、敌方各 50 血。
  - 答对：敌方 −10 血。
  - 答错或超时：我方 −10 血。
  - 每题限时 12 秒。
- **胜负**：5 题结束，我方剩余血量大于敌方即通关；否则失败。
- **解锁**：通关才解锁下一关，失败不会解锁。
- **最高纪录**：同一关只保留历史最佳，优先比较答对题数，其次剩余血量、用时。首页关卡地图与战绩页都会显示。
- **失败流程**：显示「闯关失败」，主按钮返回主页面，也可以直接重试本关。
- **通关敬礼**：每次通关后自动播放红军战士敬礼动画；第 5 关通关为「长征胜利」版本。结算页可点「再看一次敬礼」重播，按 `Esc` 或点击空白处关闭。

## 长征故事（独立板块）

`story.html` 是一张可点击的中国故事地图，与闯关完全分开，不影响关卡进度：

- 湘江血战
- 遵义会议
- 四渡赤水
- 彝海结盟
- 飞夺泸定桥
- 翻越夹金山
- 过草地
- 会师陕北

8 个地点按长征行军路线标注在中国地图上，点击地图上的编号地点或下方地点标签，右侧（手机端为下方）会打开对应故事。故事配图使用 Wikimedia Commons 的地点实景/资料照片，并已在面板中标注来源。也可以用 `story.html?id=...` 直接定位。

## 运行

推荐用本地静态服务器（多页面链接、`localStorage` 存档更稳定）：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

也可以直接双击 `index.html` 打开首页，页面之间的相对链接同样可用。

## 操作

| 场景 | 操作 |
| --- | --- |
| 选择题 | 点击选项，或按 `A` `S` `D` `F` / `1` `2` `3` `4` |
| 判断题 | 点击「正确 / 错误」，或按 `A` `S` / `1` `2` |
| 关闭敬礼动画 | 点击「继续前进」、点击空白处，或按 `Esc` |

## 存档

- 进度保存在浏览器 `localStorage`：`quizclash_campaign_v1`。
- 包含：已解锁关卡、已通关状态、每关最佳答对数、最佳剩余血量、最佳用时、尝试次数。
- 战绩页底部提供「重置长征进度」，会清空通关记录并回到第一关。

## 美术说明

- 场景与人物均为原创 SVG 二次元插画，未直接使用历史照片或影视素材。
- 首页与闯关页使用原创红日、云层与山峦组成的日出场景；故事页使用中国地图轮廓与长征路线示意，仅表示大致方位，不作为精确地理地图。
- 故事配图来自 Wikimedia Commons（地点实景/资料照片，CC BY-SA 或公有领域），用于阅读场景提示；不同资料在细节上可能存在差异。
- 场景灵感来自长征途经地：湘江、遵义、赤水河、彝海、泸定桥、夹金山、松潘草地、陕北黄土高原。
- 人物为虚构的红军战士与追兵形象，仅用于游戏叙事。
- 敬礼动画由 SVG 内部 CSS 动画驱动：抬手敬礼、旗帜摆动、红星呼吸、星点闪烁。
